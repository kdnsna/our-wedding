# A Love Story, By the Sea · 婚礼数字请柬

> 2026.11.14 · 山东威海荣成 · 华星宾馆户外草坪
> 手机端沉浸式婚礼网站（六幕滚动叙事长页）

设计依据：`婚礼专属数字请柬设计方案_V1.0.pdf`

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址即可（默认 http://localhost:5173）。
手机预览：让手机和电脑连同一 Wi-Fi，访问 `http://<电脑IP>:5173`。

## 上线前要做的事（按顺序）

### 1. 替换照片（assets/ 目录）

| 文件名 | 用途 | 建议 |
|---|---|---|
| `hero.jpg` | 第一幕主视觉双人照 | 竖构图最佳，人物完整、有留白 |
| `story-1.jpg` | 第二幕大图 | 有故事感的双人照，竖构图 |
| `story-2.jpg` | 第二幕细节照 | 牵手、眼神、互动特写，方形 |
| `gallery-1.jpg` ~ `gallery-8.jpg` | 第五幕画廊 | 景别交替；3、6 为宽幅横图 |
| `share-cover.jpg` | 微信分享封面 | 方形，含双人照为佳 |
| `bgm.mp3` | 背景音乐（可选） | 未上传时音乐按钮自动隐藏；上传后可手动开启 |

- 照片放进去就自动显示；缺哪张，对应位置会显示占位提示，不会破版。
- 建议压缩到每张 500KB 以内（可用 squoosh.app 转 WebP 后改后缀同名引用，或直接用 JPG）。

### 2. 修改文字配置（index.html 底部 `CONFIG`）

```js
const CONFIG = {
  groomName: "新郎",          // ← 改名字
  brideName: "新娘",
  ceremonyTime: "上午 10:58",  // ← 请核实最终仪式时间
  contact: "请通过微信联系新人", // ← 不公开个人手机号
  mapKeyword: "荣成华星宾馆",  // ← 地图搜索关键词
  mapCity: "威海",
  rsvpUrl: "",                 // ← 回执表单链接（腾讯问卷/金数据），留空则提示微信联系
};
```

酒店准确名称与定位请在上线前核实（设计方案中标注"待核实"）。

### 3. 部署（让亲友能用链接打开）

任选其一：

- **Vercel / Netlify**：拖入本目录即得 `https://` 链接，免费。
- **GitHub Pages**：push 到 GitHub 后在仓库 Settings → Pages 开启。
- **腾讯云 COS / 阿里云 OSS**：静态网站托管，国内访问更快，绑定备案域名后微信内打开体验最佳。

### 4. 微信分享卡片

微信内分享的标题/摘要取自页面 `<meta>` 标签，封面取 `assets/share-cover.jpg`。
如需自定义"转发给好友"的缩略卡片（JS-SDK 的 `updateAppMessageShareData`），需要已认证公众号 + 后端签名，属可选增强，未配置时微信会使用页面默认抓取。

## 六幕结构

01 The Opening 电影开场 → 02 Our Story 关于我们 → 03 The Journey 奔赴山海 → 04 The Invitation 正式邀请（含赴约指南及可选回执） → 05 The Gallery 婚纱影像→ 06 The Ending 尾声致谢

右下角常驻「婚礼信息」快捷入口，宾客可随时跳到第五幕，不必看完动画。

- 视觉主线：电影开场 → 相遇故事 → 真实影像山海 → 原文「所爱隔山海，山海皆可平」 → 正式邀请 → 六张精选婚纱照 → 尾声。
- 保留原有 MaShanZheng 字体体系及「所爱隔山海，山海皆可平」原句，不替换书法字体。
- 邀请信息前置；第一屏出现双方姓名；地点增加「荣成市成山大道东段1号」，准确草坪入口以酒店确认为准。
- 页面不再包含私人手机号码；无真实回执链接时隐藏回执入口，无音乐文件时隐藏音乐按钮。
- 首屏图片预加载，其他照片懒加载；微信分享封面改为绝对 HTTPS 地址，实际微信卡片展示仍须手机端实测。
- 海景使用项目已有 `assets/interlude.jpg`，不是经过实地确认的酒店场地影像。如后续有草坪与海景素材，可替换。
